# WarioPainter
A Warioware game made for Stardance.

The game consists of a canvas that you have to fill. You have limited time to fill as much as you can with the tools available. If you get too slow in fill the amount required you loose a life. Three strikes and your out!

The game and most the assets were done by me. Some better looking assets were done by Gabl18.
Nothing was done by AI!
